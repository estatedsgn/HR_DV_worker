# Дайвинчик auto-swiper

Автономный асинхронный сервис, который ведёт бота знакомств **Дайвинчик**
(`@leomatchbot`) от лица уже авторизованного аккаунта через мост CRMChat
(отдельный логин/сессия не нужны — переиспользуется существующая).

## Что делает

- **Анкеты на оценку** → лайк/дизлайк случайно 50/50 (`DAIVINCHIK_LIKE_PROBABILITY`).
- **«Кому-то понравилась твоя анкета» / входящие лайки** → всегда лайк
  (заходит в «режим лайкеров» и лайкает показанные анкеты, пока не вернётся в меню).
- **Взаимная симпатия (мэтч)** → достаёт `@username`/ссылку и заводит лида в воронку
  рекрутера через `LeadIntakeService` (идемпотентно). Если у мэтча нет `@username` —
  пишет в review-лог и шлёт алерт супервизору (вручную).
- **Рекламное предложение** → жмёт вторую кнопку справа
  (`DAIVINCHIK_AD_BUTTON_FROM_RIGHT`).
- **«Лайки на сегодня закончились»** → пауза на `DAIVINCHIK_LIMIT_PAUSE_MINUTES`.
- **Главное меню** → запускает просмотр анкет (отправляет «1»).
- Работает только в окне `DAIVINCHIK_ACTIVE_HOURS_START..END` в таймзоне
  `DAIVINCHIK_TIMEZONE` (по умолчанию 10:00–21:00 Europe/Moscow), 24/7.
- Всё, что не распознано, пишется в `daivinchik_review.jsonl` — это материал для
  доработки правил.

## Архитектура

- `keyboards.py` — парсит `replyMarkup` из сырых сообщений Telegram в кнопки.
- `classifier.py` — **чистая** функция `classify()` → `Decision`. Тут вся логика
  «что нажать». Тестируется без сети (`tests/test_daivinchik_classifier.py`).
- `service.py` — оркестратор: bootstrap CRMChat, резолв бота, цикл опроса,
  рабочие часы, исполнение решений, приём лида, persist state.
- `__main__.py` — точка входа (`run` / `probe`).

Дайвинчик держит **постоянную reply-клавиатуру** (❤️/👎/жалоба/💤), а анкета
приходит несколькими сообщениями (фото с пустым текстом). Поэтому сервис склеивает
текст самого свежего входящего сообщения с последней активной reply-клавиатурой
(`_effective_message`).

## Запуск

```bat
:: 24/7 (с автоперезапуском)
start_daivinchik.bat

:: или вручную
.venv\Scripts\python.exe -m app.services.daivinchik
```

Перед боевым запуском поставь `DAIVINCHIK_ENABLED=true` в `.env`.

## Отладка и доработка правил

```bat
:: показать последние сообщения бота + кнопки + какое решение примет классификатор
.venv\Scripts\python.exe -m app.services.daivinchik probe -n 12

:: контролируемый прогон на N реальных нажатий
.venv\Scripts\python.exe -m app.services.daivinchik --ignore-enabled-flag --max-actions 5
```

Цикл доработки: запустить → посмотреть `daivinchik_review.jsonl` → если бот не понял
сообщение, добавить ключевые слова/правило в `classifier.py` → добавить тест из
реального текста → перезапустить.

## Состояние

`daivinchik_state.json` хранит `last_message_id`, `liker_mode` и `paused_until`,
чтобы рестарт не переобрабатывал старое и помнил паузу по лимиту.
