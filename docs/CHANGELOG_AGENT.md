   «Да» и получила тот же вопрос ещё 2 раза).

Изменения этого пакета:

### 1) Лестница повторных касаний для замолчавших лидов (re-engagement)
- Новый сервис `app/services/funnel_graph/reengage.py`: если последнее сообщение
  в диалоге — наше и лид молчит, шлём до 3 «бампов» с нарастающими паузами
  (по умолчанию 4ч → 20ч → 48ч), потом навсегда замолкаем.
- Тексты разные для «холодных» (вообще не ответила на опенер) и «тёплых»
  (переписка была, затихла). Для тёплых — переформулированный вопрос текущей
  стадии (через QUESTION_VARIANTS), не дословный повтор.
- Защиты: не бампим, если есть неотправленные джобы в очереди; идемпотентность
  `reengage:{dialog}:{n}`; лимит на цикл; только в рабочие часы (гейт автопилота);
  терминальные стадии и пауза «до 18 лет» исключены.
- Включение: `REENGAGE_ENABLED` (вкл по умолчанию), интервалы настраиваются.
- Интеграция: `scripts/run_autopilot.py` запускает скан раз в ~5 минут.

### 2) Убран гейт salary_schedule_offer из основного пути
- Было: age_check → голосовые о работе → ВОПРОС «давай расскажу про зп?» → ждём
  «да» → голосовые про ЗП → «остались вопросики?». Каждый лишний вопрос = потеря
  части лидов (классика воронок).
- Стало: age_check → мостик-предупреждение → голосовые о работе + голосовые про
  ЗП/график ОДНИМ паком → текстовый дайджест условий → «остались вопросики?».
- `action_executor` теперь умеет проходить ЦЕПОЧКУ action-стадий за один ход.
- Стадия salary_schedule_offer оставлена в политике для обратной совместимости
  (5 живых лидов сейчас стоят на ней — их выведет существующая логика
  offer_deliver_voices).

### 3) Текстовый дайджест после голосовых (новый шаблон salary_digest_message)
- После голосовых уходит короткий текст: выплаты на РФ-карту еженедельно (на
  стажировке — после смены), график гибкий. Если девочка не слушает голосовые —
  инфа всё равно дойдёт. Цифры намеренно НЕ называем (политика: конкретика на
  собесе).

### 4) Подтверждение «18+» словами
- `semantic.py`: на age_check утвердительный ответ («да», «конечно», «есть»)
  засчитывается как 18+ ЕСЛИ наш последний вопрос упоминал «18». Возраст пишем
  как 18, на собесе всё равно проверяют документы.
